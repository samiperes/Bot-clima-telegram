# Bot do Clima
Bot que informa o clima atual de qualquer cidade, usando a API [Weatherstack](https://weatherstack.com/).

## Como usar o bot
- `/start` – mostra um guia
- `/clima <cidade>` – mostra o clima da cidade (se for pesquisar o de Hortolândia, escreva sem acento)
- Ou envie apenas o nome da cidade

## Como rodar
1. Instale as dependências: `pip install -r requirements.txt`
2. Copie `.env.example` para `.env` e preencha o token do Telegram (BotFather) e a chave da Weatherstack
3. Execute: `python bot.py`
