Bot que informa o clima atual de qualquer cidade, usando a API [Weatherstack](https://weatherstack.com/).

## Como usar
- `/start` – para começar
- `/clima <cidade>` – mostra o clima da cidade (se for pesquisar o de Hortolândia, escreva sem acento) ou envie apenas o nome da cidade

## Como rodar
1. Tenha o Python instalado em seu computador
2. No terminal, rode: `pip install -r requirements.txt`
3. Depois, rode: `python bot.py`
